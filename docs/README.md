## ⚠️ 文档纪律（避免又变旧）

⭐ **每个"会被人找"的目录都有自己的 `README.md` 写明定位** —— 加文件前先看一眼。

⭐ **改代码时顺手看这几处会不会过期**：
| 改了什么 | 要同步的文档 |
|---|---|
| 加/删**开关** | `core/debug.hpp` 头部 + `README.md` 的调试体系节 |
| 加/删**算法槽位** | `README.md` 的「可插拔的算法槽位」表 |
| 改**配置分层** | `params/README.md` + `README.md` 的相机节 |
| 改**目录结构** | 各目录自己的 `README.md` + `README.md` 的目录结构节 |
