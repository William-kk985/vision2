## 3. ⚠️ 唯一一处真行为改动：**W83 选目标的排序**

```cpp
// 同济上游 tracker.cpp:53-58  ⚠️ 硬编码 1440×1080
armors.sort([](const Armor & a, const Armor & b) {
  cv::Point2f img_center(1440 / 2, 1080 / 2);  // TODO
  return cv::norm(a.center - img_center) < cv::norm(b.center - img_center);
});

// 本项目 W83  ✅ 归一化坐标，与分辨率无关
armors.sort([](const Armor & a, const Armor & b) {
  const cv::Point2f center_norm(0.5f, 0.5f);
  return cv::norm(a.center_norm - center_norm) < cv::norm(b.center_norm - center_norm);
});
```

| | 同济 | 本项目 |
|---|---|---|
| 中心点 | ⚠️ **硬编码 `(720, 540)`** | ✅ **归一化 `(0.5, 0.5)`** |
| 用哪个字段 | `a.center`（**像素**） | `a.center_norm`（**归一化**） |
| 相机 **1440×1080** | ✅ **正确**（同济相机就是这个） | ✅ 正确 |
| 相机 **1280×720** | ⚠️ **真实中心是 (640,360)，却算成 (720,540)**<br>⇒ **排序偏向右下角 ⇒ 多装甲板时选错目标** | ✅ **正确** |

⭐ **判定**：**这是"适配本项目硬件"的修复，不是"改算法"**。
⭐ **同济的代码在他们自己的相机上是对的** —— 硬编码值恰好匹配。
⭐ **本仓库相机是 1280×720** ⇒ 不改就**真的会选错目标**。
