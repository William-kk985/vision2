## 一、⭐ 核心原则：**双轨制**

| | ⭐ 运行期（哈工程启发） | ⭐ 编译期（本项目强化） |
|---|---|---|
| **手段** | sink 热插拔（按键 1/2/3/4）、日志级别（`d`）、`--log-off` | ⭐ **`core/debug.hpp`**（开关与实验总控）的 `LOG_XXX` / `HZMIR_EXP_*`、`--tongji`、`*_impl` |
| **优点** | ⭐ **不用重编**，快速看大体情况 | ⭐ **零成本**（实测 1.65 ns vs 89 ns） |
| **代价** | ⚠️ 有运行期开销；⚠️ 热键多记不住 | ⚠️ 改一次要重编 |
| **适合** | 赛场快速切、临时试 | 长期调试、性能敏感的逐帧日志 |

**⇒ 两者不是替代关系，是**分层**：**

```
┌─ 编译期（决定"编不编"）─────────────────────────────┐
│  LOG_YOLO / LOG_EKF / ... ← 逐帧细节日志（默认关）    │
│  *Impl 运行期选实现 ← 算法置换（单二进制多实现）      │
└──────────────────────────────────────────────────────┘
                       ↓
┌─ 运行期（决定"打不打 / 挂不挂"）────────────────────┐
│  SinkHub 热插拔（1窗口 2CSV 3PlotJuggler 4存图）     │
│  日志级别 d（debug→info→warn→err→off）              │
│  --log-off / --log-only（临时按模块静音）            │
└──────────────────────────────────────────────────────┘
```

## 五、⭐ 判据：什么时候用宏、什么时候用运行期

```
                  ┌─ 关掉后会让人误判"功能坏了"吗？ ─┐
                  │                                   │
                会 │                                   │ 不会
                  ↓                                   ↓
        ⭐ 用运行期（可热插拔）              ⭐ 可以（也应该）用宏
        · 可视化窗口 / 存图                  · 细节日志（LOG_*）
        · 任何"用户会找它"的功能             · 逐帧统计
                  │                                   │
                  └─────────────┬─────────────────────┘
                                ↓
                  ┌─ 关掉后能省到真实开销吗？ ─┐
                  │                             │
                不能 │                           │ 能
                  ↓                             ↓
        ⚠️ 别做宏（省不到，只剩误导）   ⭐ 用宏（零成本）
        · L3 存图（依赖本来就链接）      · 含昂贵参数的日志
        · 任何只是"if 一下"的东西        · 每帧的格式化
```

**⇒ 一句话：⭐ 宏用于「**关掉后语义不变、且真能省开销**」；运行期用于「**用户会找它、关了要能马上开回来**」。**
