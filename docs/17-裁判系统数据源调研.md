## 一、⭐ 找到了什么

**`TongjiSuperPower/sp_referee`**（同济的「miniPC 裁判系统数据读写」）
—— ⚠️ 它是 **ROS1** 工程（`ros::NodeHandle` / `ros::Publisher`），
读 **`/dev/referee` 串口**，把裁判协议解成 ROS 消息。

### 它带的东西（⭐ 这才是价值所在）

| 文件 | 内容 |
|---|---|
| ⭐ **`include/sp_referee/protocol.h`** | **完整的 RoboMaster 裁判系统命令表**（29 个 `RefereeCmdId`） |
| ⭐ **`include/sp_referee/data.h`** | 30 个协议 struct（帧格式） |
| **`msg/*.msg`** | 11 个 ROS 消息定义 |
| `src/read.cpp`（32 KB）| 串口收包 + 解包（含双缓冲拼接） |
| `src/write.cpp` | 发包（图传/交互数据） |

### ⭐ `protocol.h` 里的命令表（摘与我们相关的）

```
GAME_STATUS_CMD          = 0x0001   ← ⭐⭐ 比赛阶段（我们最想要的）
GAME_ROBOT_HP_CMD        = 0x0003   ← ⭐ 机器人血量
ROBOT_STATUS_CMD         = 0x0201   ← ⭐ 等级 / 热量上限 / 底盘功率限制
POWER_HEAT_DATA_CMD      = 0x0202   ← ⭐ 枪管热量 / 缓冲能量 / 电压电流
BUFF_CMD                 = 0x0204   ← 增益
HURT_DATA_CMD            = 0x0206   ← 受伤
SHOOT_DATA_CMD           = 0x0207   ← ⭐ 弹速 initial_speed / 射频
RFID_STATUS_CMD          = 0x0209   ← 点位
RADAR_MARK_DATA_CMD      = 0x020C   ← 雷达标记
SENTRY_INFO_CMD          = 0x020D   ← 哨兵信息
REMOTE_CONTROL_CMD       = 0x0304   ← 遥控器
MAP_*_CMD                = 0x0305+  ← 雷达站
```

## 二、⚠️ `sp_referee` **没解析** `GAME_STATUS`

`data.h` 的 30 个 struct 里**没有** `game_status` ⇒ 它发布的 5 个话题是：

| 话题 | 消息 | ⭐ 能填什么 |
|---|---|---|
| `/robot_status` | `RobotStatusMsg` | ⭐ **`current_hp` / `maximum_hp` / `robot_level` / `shooter_barrel_heat_limit` / `chassis_power_limit`** |
| `/power_heat_data` | `PowerHeatDataMsg` | ⭐ **`shooter_17mm_1/2_barrel_heat` / `buffer_energy` / `chassis_voltage/current/power`** |
| `/shoot_data` | `ShootDataMsg` | ⭐ **`initial_speed`（弹速！）/ `launching_frequency`（射频）** |
| `/rc_data` | `RemoteControlMsg` | 遥控器 |
| `/radar_mark_data` | `RadarMarkDataMsg` | 雷达标记 |

⭐ **`RobotStatusMsg` 还自带机器人 ID 枚举**（可直接用于目标识别）：
```c
RED_HERO=1  RED_ENGINEER=2  RED_STANDARD_3=3  RED_STANDARD_4=4  RED_STANDARD_5=5
RED_AERIAL=6  RED_SENTRY=7  RED_RADAR=9
BLUE_*=101..109
```

## 五、⭐ 一句话结论

> **`game_state` 不再是"架构上缺一层"，而是"缺一个驱动"** ——
> 协议、帧格式、字段名**全都有了**（`sp_referee/include/sp_referee/{protocol,data}.h`），
> 只差**把串口读进来**（ROS2 移植 或 自写 serial 驱动）+ **补一个没解析的 `0x0001`**。
>
> ⭐ **额外收获**：**`ShootDataMsg.initial_speed` 让 B6（`RlsBulletSpeed`）从"阻塞"变成"可做"**。
